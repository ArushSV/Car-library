## Car Information and Comparison System


## 1. Problem Statement

Finding and comparing specifications of different cars can be difficult when the information is scattered. This project provides a simple Python-based system where users can view car details, compare two cars, and create a list of their favourite cars.

## 2. Scope of the Project

The project covers information about 15 cars and provides basic operations such as:

- Viewing car information
- Selecting a random car
- Comparing two cars
- Creating a Top 3 favourite-car list
- Handling invalid inputs

The project is a console-based application and does not use an external database or graphical interface.

## 3. Target Users

- Car enthusiasts
- Students learning Python
- Users interested in comparing car specifications
- Beginners who want to explore car-related data

## 4. High-Level Features

- Car Information: View complete specifications of a selected car.
- Random Car: Display information about a randomly selected car.
- Car Comparison: Compare specifications of two cars.
- Favourite Cars: Create a Top 3 list of favourite cars.
- Input Validation: Detect invalid car numbers.
- Menu System: Simple and easy-to-use console interface.
